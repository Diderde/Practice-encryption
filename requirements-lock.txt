# 已验证依赖版本快照（本机 .venv 实测）。安装请带摘要校验：
#     python -m pip install --require-hashes -r requirements-lock.txt

# 为什么带 --hash：本机 pip 走清华镜像、CI 走默认 PyPI——**两条渠道不同源**。版本号钉死
# 只能保证"解析结果相同"，本文件把每个包可被选中的发行件逐个登记 sha256，两条渠道各自
# 校验同一份摘要，才能证明拿到的是**同一批字节**。换平台/解释器需重生成（本仓实测环境
# 是 CPython 3.12 / Windows x64；3.11 下 numpy==2.5.3 上游已无发行件，故可选依赖的钉版
# 实际从 3.12 起——`requires-python >= 3.11` 指的是"零可选依赖也能跑"这层，CI 最小作业
# 在 3.11/3.12 上验的就是它）。

# 口径：
#   - 只登记 Python 包；pip、setuptools 由 venv/runner 自带（锁它们等于用 requirements
#     升级包管理器本身）。
#   - 工具链不在此列：Rust 1.98.1 与 MSVC BuildTools / Windows SDK 见
#     Licenses/README.md §3 的登记。
#   - `start.bat` 是交互式修复路径，按版本号安装、**不**校验摘要；开发安装与 CI 走本锁。
#   - 升级任一依赖时重生成：`pip download --no-deps --only-binary=:all: --python-version
#     3.12 --implementation cp --platform win_amd64 --abi cp312 <pin>...` 取发行件，逐个算
#     sha256 重登记；对账脚本用 PyPI JSON（pypi/<name>/<ver>/json 的 digests.sha256）。
